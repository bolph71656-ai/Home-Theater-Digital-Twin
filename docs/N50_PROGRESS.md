## Key risks

- Legacy G10 Context exposes one measurement point plus a `speakers` collection; the adapter must use that shape only as an ID/position carrier and must not leak speaker semantics onto seats/furniture.
- G10 footprint profiles are radial while N40 bodies are rectangular. N50 uses a conservative envelope and must not describe it as exact mesh collision.
- Legacy wall edge IDs are endpoint-derived and not stable across topology changes. Persistent native constraints therefore store stable N30b `wall_id` only.
- Hide/lock must not alter feasibility.
- Rejected preview must not add history or silently commit.
